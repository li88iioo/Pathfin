## Connecting

**The server can't be added, or I get "The server uses HTTP. Allow it explicitly in server settings first".**
Pathfin uses HTTPS by default. For a plain `http://` server on your LAN, turn on **Allow plain HTTP connections and playback** for that server. Redirects that downgrade HTTPS to HTTP are blocked.

**"The server requires a redirect" / "The server address can't contain query parameters or fragments".**
Enter the final server address, for example `https://jellyfin.example.com` or `http://192.168.1.10:8096`. Don't include `?…`, `#…` or an account in the address.

**"Server certificate verification failed".**
The certificate doesn't match the domain or isn't trusted by Android. Fix the certificate or reverse proxy on the server side; Pathfin doesn't skip certificate checks.

**Can I use several addresses for one server?**
Yes. Add fallback addresses to the server, such as a LAN address and a public address.

## STRM playback

**What does "STRM original address" do?**
When it's on, Pathfin plays the HTTP(S) address inside the STRM file directly. When it's off, playback goes through Jellyfin's playback address. Find it under **Settings → Play → Media source**.

**Which STRM sources are supported?**
STRM direct playback and STRM quality switching have only been tested with STRM files generated by [MediaFlux](https://github.com/li88iioo/MediaFlux) and with Guangya Cloud Drive (光鸭云盘). Other STRM sources may work, but they are untested.

**Why are some quality levels grey in the player's quality menu?**
Cloud qualities come from resources that already exist on the cloud drive. Grey levels aren't provided for this file. Quality switching needs a server that implements `mediaflux.playback.v1`.

**What does "STRM default quality" change?**
Only which quality STRM with the quality protocol starts at next time. Local files and Live TV aren't affected, and it only applies while **STRM original address** is on.

**"This device doesn't support this original quality".**
Pathfin never silently switches STRM to Jellyfin transcoding. Pick another source or a lower cloud quality, or turn off **STRM original address** and choose a server quality.

**A local server path like `/mnt/media/…` doesn't play.**
A path on the server's disk isn't reachable from the phone. The STRM must contain an HTTP(S) address the phone can access.

## Playback

**The video won't play, or only audio plays.**
Pathfin prefers the system decoder. On ARM64 devices it can fall back to FFmpeg software decoding for H.264/HEVC, including Hi10P and Dolby Vision Profile 5. Software decoding is limited to 4096×2304, and whether it's smooth depends on the device. Check **Settings → Play → Decoding & subtitle rendering**. On non-ARM64 devices the software fallback isn't available.

**ASS subtitles look plain.**
Styled ASS rendering uses libass, which is ARM64 only. Other architectures use basic subtitles. If the extension fails, the app falls back to basic subtitles and shows a notice.

**Online subtitle search returns nothing.**
Online search needs a subtitle provider plugin on the server and permission for your account. Uploaded and found subtitles are saved to Jellyfin.

**What gestures does the player support?**
Double-tap the sides to seek, long-press for temporary speed-up, swipe horizontally to seek, and pinch to switch between fit and fill. Long-press speed and swipe seeking can be adjusted in settings.

## Library

**How do I act on several items at once?**
Long-press a cover in a library to start selecting, then tap more covers. Use the **More** button in the title bar to mark them played or unplayed, refresh metadata or delete them. Press back or the × to cancel. Delete and refresh need the matching permissions on the server.

**What do the metadata refresh options mean?**
- **Scan for new and updated files**: checks for file changes only.
- **Search for missing metadata**: fills in missing information.
- **Replace all metadata**: fetches everything again, overwriting manual edits.

The last two can also replace existing images and trickplay previews.

## Downloads, Live TV and DLNA

**Why can't an STRM item be downloaded?**
An STRM is a text file containing an address, not a video. Only actual HTTP(S) media files can be downloaded.

**Downloads stay waiting.**
Check the download network rule. With **Unmetered networks only**, Android decides when a network counts as unmetered. Changing the rule requeues tasks, and unfinished downloads start over.

**Live TV doesn't appear.**
Live TV must be set up on the server, and **Enable Live TV** must be on in settings. **Direct live source** plays the channel's source address without server transcoding, which may fail if the device can't decode it.

**DLNA casting fails for some items.**
DLNA doesn't support HLS/DASH manifests or STRM text yet. Choose an item that is a direct media file.

## Others

**How do I switch the language?**
Choose it in **Settings → Preferences → Language**. It follows the system by default and supports English and Simplified Chinese. On Android 13 and later you can also set it per app in system settings.

**How do I update the app?**
Use **Settings → About → Check for updates**. Pathfin downloads the stable GitHub release, checks its package name, signature and version, and hands it to the system installer; the package is deleted after installation. The first time, Android asks you to allow Pathfin to install unknown apps. Automatic checks run at most once a day and can be turned off on the same page.

**How do I report a crash?**
Open **Settings → About → Crash log** and tap **Send feedback**. It opens a new GitHub issue with your device info and the latest crash record. Tokens, passwords and server addresses are hidden, but review the text before posting.

**Can the debug and release builds be installed together?**
Yes. They use different package names and keep separate data.

**Where do I report a problem?**
Open an issue at [GitHub Issues](https://github.com/li88iioo/Pathfin/issues) with your device model, Android version, Jellyfin version and the steps that reproduce it. Don't post server addresses, tokens or passwords.

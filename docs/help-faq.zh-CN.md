# 帮助与常见问题

[English](help-faq.md) | 简体中文

## 连接

**无法添加服务器，或提示“服务器使用 HTTP，请先在服务器设置中明确允许”。**
Pathfin 默认使用 HTTPS。局域网内的 `http://` 服务器，需要在该服务器设置中开启“允许 HTTP 明文连接与播放”。从 HTTPS 降级到 HTTP 的跳转会被阻止。

**提示“服务器要求重定向”或“服务器地址不能包含查询参数或片段”。**
请填写最终的服务器地址，例如 `https://jellyfin.example.com` 或 `http://192.168.1.10:8096`，不要带 `?…`、`#…` 或账号。

**提示“服务器证书校验失败”。**
证书与域名不匹配或不受 Android 信任。请在服务器或反向代理侧修正证书，Pathfin 不会跳过证书校验。

**一个服务器能配置多个地址吗？**
可以。为服务器添加备用地址，例如局域网地址和公网地址。

## STRM 播放

**“STRM 原始地址”有什么作用？**
开启后，Pathfin 直接播放 STRM 文件里的 HTTP(S) 地址；关闭后使用 Jellyfin 播放地址。位置在 **设置 → 播放 → 媒体源**。

**支持哪些 STRM 来源？**
STRM 直连播放与 STRM 画质切换目前仅在 [MediaFlux](https://github.com/li88iioo/MediaFlux) 生成的 STRM 和光鸭云盘上测试通过。其他来源的 STRM 可能可用，但未经验证。

**播放器画质菜单里为什么有些档位是灰的？**
云盘画质来自网盘上已有的资源，灰色档位表示该文件没有对应画质。画质切换需要服务端实现 `mediaflux.playback.v1`。

**“STRM 默认画质”影响什么？**
只决定支持画质协议的 STRM 下次起播使用的画质，不影响本地文件和直播，且仅在开启“STRM 原始地址”时生效。

**提示“本机不支持此原画”。**
Pathfin 不会把 STRM 悄悄改成 Jellyfin 转码。请更换片源或选择较低的云盘画质，也可以关闭“STRM 原始地址”后选择服务器画质。

**`/mnt/media/…` 这类服务器本地路径无法播放。**
服务器磁盘上的路径手机访问不到，STRM 里必须是手机能访问的 HTTP(S) 地址。

## 播放

**视频无法播放，或只有声音。**
Pathfin 优先使用系统解码器。ARM64 设备上，H.264/HEVC（含 Hi10P 和 Dolby Vision Profile 5）可回退到 FFmpeg 软件解码。软件解码上限为 4096×2304，是否流畅取决于设备。可在 **设置 → 播放 → 解码与字幕渲染** 中调整。非 ARM64 设备没有软件回退。

**ASS 字幕没有样式。**
ASS 样式渲染使用 libass，仅支持 ARM64，其他架构使用基础字幕。扩展出错时会自动回退基础字幕并给出提示。

**在线搜索字幕没有结果。**
在线搜索需要服务器安装字幕提供商插件，并且账号有相应权限。上传和在线找到的字幕会保存到 Jellyfin。

**播放器支持哪些手势？**
双击左右两侧快退或快进，长按临时倍速，横向滑动调整进度，双指缩放在原始比例和裁切填满之间切换。长按倍速和滑动进度可在设置中调整。

## 媒体库

**怎样同时操作多个条目？**
在媒体库长按封面进入多选，再点选其他封面。点标题栏的“更多”可批量标记为已播放或未播放、刷新元数据或删除。按返回键或 × 取消选择。删除和刷新需要服务器上的相应权限。

**刷新元数据的选项有什么区别？**
- **扫描新的和有修改的文件**：只核对文件变化。
- **搜索缺少的元数据**：补全缺失的信息。
- **覆盖所有元数据**：重新获取全部信息，会覆盖手动编辑的内容。

后两项还可以选择替换现有图片和进度条预览图。

## 下载、直播与 DLNA

**为什么 STRM 条目不能下载？**
STRM 是记录地址的文本文件，不是视频，只能下载实际的 HTTP(S) 媒体文件。

**下载一直在等待。**
请检查下载网络规则。选择“仅不计费网络”时，是否计费由系统判断。更改规则会重新排队，未完成的下载从头开始。

**看不到直播电视。**
需要先在服务器上配置直播电视，并在设置中开启“启用直播电视”。“直连直播源”直接播放频道源地址，不经服务器转码，设备不支持其编码时可能无法播放。

**部分条目无法 DLNA 投屏。**
DLNA 暂不支持 HLS/DASH 清单或 STRM 文本，请选择直接媒体文件。

## 其他

**怎样切换语言？**
在 **设置 → 常规 → 语言** 中选择，默认跟随系统，支持简体中文和英文。Android 13 及以上也可以在系统设置中单独设置。

**怎样更新应用？**
在 **设置 → 关于 → 检查更新** 下载 GitHub 正式版。Pathfin 会校验包名、签名和版本后交给系统安装器，安装完成后删除安装包。首次安装时系统会要求允许 Pathfin 安装未知应用。自动检查每天最多一次，可在同一页面关闭。

**怎样反馈崩溃？**
打开 **设置 → 关于 → 崩溃日志**，点“提交反馈”会在 GitHub 新建 Issue，并附上设备信息和最近一条崩溃记录。令牌、密码和服务器地址已被隐藏，公开前仍请检查内容。

**开发版和正式版能同时安装吗？**
可以。两者包名不同，数据互相独立。

**在哪里反馈问题？**
请在 [GitHub Issues](https://github.com/li88iioo/Pathfin/issues) 提交，附上设备型号、Android 版本、Jellyfin 版本和复现步骤。不要贴出服务器地址、令牌或密码。
